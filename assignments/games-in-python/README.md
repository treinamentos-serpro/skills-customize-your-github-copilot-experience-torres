
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e seleção aleatória em Python ao criar um jogo de adivinhação de palavras.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie o clássico jogo da forca. O jogador deve adivinhar, uma letra por vez, uma palavra escolhida aleatoriamente antes de esgotar as tentativas disponíveis.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso da palavra no formato `_ _ _`.
- Rastrear e informar quantas tentativas incorretas ainda restam.
- Encerrar quando a palavra for adivinhada ou quando as tentativas se esgotarem.
- Exibir uma mensagem indicando vitória ou derrota.
